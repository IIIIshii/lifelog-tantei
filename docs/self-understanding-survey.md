# 自己理解が深まったかを測る質問

ほかの人に使ってもらうとき(#199)と、自分たちで使い続けるとき(#198)に、同じ質問を聞くためのメモです。
測りたいのは、「使う前より、自分の好きなこと・得意なこと・苦手なことを、理由つきで言えるようになったか」です。

## 聞くタイミング

| いつ | 何をするか |
|---|---|
| 使い始める日(アプリを渡す前) | 「使う前の質問」に答えてもらう。アプリは、まだ見せない |
| 1〜2週間使ったあと | 「使ったあとの質問」に答えてもらう。使う前の答えは、見せない |

使う前の答えは、使ったあとに見せません。見せると、前の答えに合わせて書いてしまうためです。

## 使う前の質問

1. 次の3つを、思いつくだけ、理由もつけて書いてください。3つずつ書けなければ、書けた数だけでかまいません。
   - 好きなこと
   - 得意なこと
   - 苦手なこと、または気が重くなること
2. 自分のことを、どのくらい分かっていると思いますか。1(まったく分からない)から5(よく分かっている)で選んでください。
3. 「やりたいこと」はありますか。「ある」「ない」「よく分からない」から選んでください。「ある」なら、それも書いてください。

## 使ったあとの質問

1. 使う前と同じ質問を、もう一度書いてください(上の1〜3)。アプリは見ずに、今の自分の考えで書いてください。
2. 使っているあいだに、「そうだったのか」と思った気づきはありましたか。あれば、次を教えてください。
   - どんな気づきか
   - 探偵に言われて気づいたのか、自分で気づいたのか
3. 探偵(質問・今日のコメント・所見)が言ったことのうち、当たっていたことと、外れていたことを教えてください。
4. 続けたいと思いますか。その理由も教えてください。
5. 手が止まったところは、どこでしたか。

## 結果の見方

使う前と使ったあとの答えを、次の4つで比べます。

| 見る点 | 例 |
|---|---|
| 挙げられた数 | 好きなことが2つから4つに増えた |
| 理由の具体さ | 「楽しいから」から「教えて相手が分かった顔をすると嬉しい」に変わった |
| 前になかったものが出たか | 使う前は書けなかった「苦手なこと」が書けた |
| 気づいたのは誰か | 自分で気づいた気づきの数と、探偵に言われて気づいた数 |

- 「自分のことを分かっている」の自己評価(1〜5)は、補助の材料にします。人は、使うと自分に厳しくなって、点が下がることもあります。数字だけで効果を判断しません。
- 探偵の言ったことの当たり外れは、外れたものを特に集めます。外れが多い言い方は、質問や所見の指示を直す材料になります。

## 注意すること

- 人数が少ないので、割合や平均で効果を言い切りません。「5人中3人が、理由つきで挙げられる数が増えた」のように、人数と実際の答えを、そのまま書きます。
- 使っただけで変わったとは言い切れません。「使ったあとに増えた」と書き、「使ったから増えた」とは書きません。
- ES や発表には、実際にあったことだけを書きます。聞いた答えは、本人の了承を得てから使います。
- 日記の中身は聞きません。見せるかどうかは、本人が決めます。
- 聞き手は、答えを誘導しません。「好きなことは、人に教えることではないですか」のような聞き方はしません。

## 今ある機能と、これから足す機能

今のアプリで測れるのは、質問(聴取)、今日のコメント、所見に対する反応です。
「好き・得意・苦手」を貯めて見せる画面(自己理解ノート)はまだありません。ノートができたら、使ったあとの質問に、「ノートに書かれていたことは、当たっていたか」を足します。
